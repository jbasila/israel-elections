# 26th Knesset election (27 Oct 2026)

Fetched 2026-10-31. Results are **not yet certified** (CEC certifies on 2026-11-04) — re-check after.

| File | Contents |
|---|---|
| `knesset26_results.csv` | Votes and seats per list (36 lists; votes sum to 5,690,685, seats to 120) |
| `knesset26_summary.csv` | Registered voters, valid/invalid votes, turnout, threshold |
| `knesset26_turnout_by_sector.csv` | Turnout by sector/locality — **press estimates**, not official |
| `knesset26_surplus_agreements.csv` | Surplus-vote agreements (model reproduces official seats exactly with these) |
| `knesset26_blocs.csv` | Bloc assignment per list |
| `scenario_sweep.csv` | Generated by `scripts/turnout_sweep.py` — see root README |

## Caveats
- Party results come from Wikipedia, citing the Central Elections Committee. The CEC site (votes26.bechirot.gov.il) did not load during fetching.
- Surplus-vote agreements are compiled from press reports (JPost, Times of Israel), not the CEC.
- No official breakdown of turnout by sector exists. Figures are election-night press reports; Haredi town numbers are early-evening partials. There is no data for the Jewish non-Haredi or Druze sectors.
- Two withdrawn lists, Achi and Blue and White, received 0 votes and are omitted.
